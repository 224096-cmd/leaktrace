# LeakTrace（リークトレース）

個人情報漏えいの仕組みと対策を、攻撃と防御の両方の体験から学ぶWeb教材です。

- 公開URL: https://224096-cmd.github.io/leaktrace/
- 完全クライアントサイド（サーバー不要）。入力は外部に送信しません。一度開けばオフラインでも動作します。
- 扱うデータはすべて架空です。実在の人物・企業・サービスは登場しません。
- 想定端末：タブレット・PC（スマホでも表示可）

## 構成

最近の実際の漏えい事件と同じ「型」の出来事を、架空の会社で再現して体験します。各ステージの冒頭に、報道・公的資料に基づく「事件ファイル」（出典つき）を表示します。各ステージは「①見る → ②破る → ③なぜ守れるか」の三段構成です。

| ステージ | もとにした事件・統計 | ①見る | ②破る | ③なぜ守れるか |
|---|---|---|---|---|
| 0 漏えいはなぜ起きる？ | 2025年 上場企業の漏えい180件・3,063万人分（東京商工リサーチ） | 原因別の統計、データの足あと（一日の中で情報を預けている先の図） | 「これは個人情報？」の仕分け | 情報セキュリティの3要素 |
| 1 不正ログイン | IPA 10大脅威2026（個人）、闇サイトでのアカウント情報流通 | ハッシュ化 | 流出リストでリスト型攻撃 | 多要素認証／計算速度の実測と解読時間の推定 |
| 2 フィッシング | 2025年 証券口座乗っ取り、フィッシング報告245万件 | URLの読み方、中継型フィッシングの図 | 偽メールの要素を選ぶ | 偽サイトの怪しい箇所探し、認証方式の比較（パスキー）、メール・SMSの判別課題 |
| 3 ランサムウェア | アスクル・アサヒ（2025）、イセトー（2024） | 委託先から全社停止までの連鎖 | 入口を選んで連鎖をたどる | 予算3つで対策を選び、遮断箇所と被害を比較 |
| 4 人為ミス | 山形市の小学校の名簿誤添付（2025） | 誤添付とCC/BCC、共有リンクの公開範囲の図 | 時間に追われての一斉送信（添付・宛先） | 確認なし／ありの2条件で実測 |
| まとめ 漏えいの後に | 改正個人情報保護法の報告義務、通知を装った詐欺 | 漏えい通知への対応 | | 自分の行動のふり返り |

対象：中学生〜大学生。全員が同じ内容を学びます。基本の説明は中学生にも分かる言葉で書き、発展的な内容は各ステージの「🔎 もっと深く」を開くと読めます。

ほかに、攻撃経路マップ（`#/map`：通った経路の再生、対策による遮断、自社の外で起きる線の区別）と用語集（`#/glossary`）があります。

## 評価のための機能（研究・授業評価で使う場合のみ）

ホームの「研究・授業評価で使う場合」から開きます。授業で使うだけなら受けなくてもかまいません。

- **はじめのテスト／おわりのテスト**（`#/test/pre`・`#/test/post`）：同じ問題を順番を変えて出題。はじめのテストでは正誤を表示しない。
  - 知識・判断（12問）：中学校技術「D 情報の技術」、高等学校 情報Ⅰ「情報社会の問題解決」、大学の情報倫理で扱う内容（個人情報の定義、要配慮個人情報、情報セキュリティの3要素、不正アクセス禁止法、漏えい時の報告義務、委託先の監督、行動の判断）。`data/test-items.json` の `items`
  - メール・SMSの判別（5問）：ステージ2の練習問題とは別の、テスト専用の問題。`data/test-items.json` の `phish`
  - 理解の自己評価・行動意図：各4項目、5段階
- **使いやすさアンケート**（`#/survey`）：SUS（10項目、0〜100点に換算）と自由記述
- 学習の流れ：はじめのテスト → ステージ1〜4 → 最終課題 → おわりのテスト → アンケート

### 問題の追加・修正方法

`data/test-items.json` の `items` に次の形で追加します（`ans` は正解の番号。最初の選択肢が 0）。

```json
{ "id": "k1", "cat": "know", "q": "問題文", "opts": ["選択肢A", "選択肢B", "選択肢C"], "ans": 1 }
```

`cat` は `know`（知識）または `action`（行動の判断）。学習者には自動で「わからない」の選択肢が付きます。

## 学習記録

「学習記録」画面から、まとめ Markdown・操作ログ CSV・実測値 CSV・テストとアンケート CSV・全データ JSON を書き出せます。記録は端末のブラウザ内（localStorage）にのみ保存されます。

## 倫理・法令

攻撃の体験は模擬環境の中でのみ成立する簡略化した操作であり、現実のシステムに使える手順は含みません。パスワードの解読時間は、実際に解読するのではなく「組み合わせ総数 ÷ 実測した計算速度」で見積もります。教材冒頭で不正アクセス禁止法と学習の目的を説明し、同意してから始めます。
