# LeakTrace（リークトレース）

個人情報漏えいの仕組みと対策を、攻撃と防御の両方の体験から学ぶWeb教材です。

- 公開URL: https://224096-cmd.github.io/leaktrace/
- 完全クライアントサイド（サーバー不要）。入力は外部に送信しません。
- 扱うデータはすべて架空です。実在の人物・企業・サービスは登場しません。

## ステージ構成

1. パスワード — ハッシュ化、リスト型攻撃、総当たり時間の実測、多要素認証
2. フィッシング — URLの構造、偽画面の要素、本物/偽物の判別課題
3. 侵入の連鎖 — 侵入から権限拡大・持ち出しまでを1本の流れで見る
4. 人為ミス — CC/BCC、共有リンクの公開範囲、誤送信の体験
- 最終課題 — 自分の普段の行動を架空シナリオで確かめる

深さは「導入（中学生〜）」「体験（高校生〜）」「探究（大学生〜）」の3層から選べます。

## 倫理・法令

攻撃の体験は模擬環境の中でのみ成立する簡略化した操作であり、現実のシステムに使える手順は含みません。教材冒頭で不正アクセス禁止法と学習の目的について説明します。

## 開発

HTML / CSS / JavaScript のみ。`main` ブランチへ push すると GitHub Actions が GitHub Pages へ自動公開します。
